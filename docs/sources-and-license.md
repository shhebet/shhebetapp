# Open-Source Sources And License

Pinned upstreams are stored in `third_party/sources.lock.json`.

The selected repository license is `GPL-3.0-or-later` because the requested
Telegram source bases are GPL-family projects, and Telegram Web A is GPL v3.
GPL allows commercial use, but redistributed binaries and modified sources must
follow GPL terms.

Implementation rule for this repository:

- Do not copy assets, trademarks, or private local project files.
- Use the upstreams as source references and compatible code bases.
- Keep Telegram attribution and trademark separation clear.
- Prefer independent Shhebet code unless a copied upstream file is deliberately
  vendored with license headers and notices.
